# ส่วน A — ทำความเข้าใจ SFAS

## A1. SFAS คืออะไร และอยู่ตรงไหนในกระบวนการ

```
STEEP + Five Forces + CPM ──► O/T ──► EFAS (10 ปัจจัย, 2.53)
                                                              ╲
                                                               ──► SFAS (12 ปัจจัย, 2.58) ──► TOWS ──► กลยุทธ์
                                                              ╱
ทรัพยากร + Core Competency + VRIO ──► S/W ──► IFAS (10 ปัจจัย, 2.64)
```

- **SFAS = Strategic Factors Analysis Summary** (Wheelen & Hunger)
- **EFAS** ดูปัจจัยภายนอก และ **IFAS** ดูปัจจัยภายใน แยกกันคนละตาราง ส่วน **SFAS เอาทั้งสองมาไว้ในตารางเดียว** แล้วถามว่า *"ในบรรดาปัจจัยทั้งหมด ตัวไหนสำคัญที่สุดต่อการเลือกกลยุทธ์"*
- SFAS ทำ 3 อย่างที่ EFAS และ IFAS ไม่ได้ทำ:
  1. **คัด** — ตัดปัจจัยที่สำคัญน้อยหรือซ้ำซ้อนออก (20 → 12)
  2. **ให้น้ำหนักใหม่** — น้ำหนักของ 12 ปัจจัยรวมกันเท่ากับ 1.00 ปัจจัยภายในกับภายนอกจึงต้อง "แข่งกัน" ว่าตัวไหนสำคัญกว่า
  3. **เพิ่ม Duration** — บอกว่าแต่ละปัจจัยต้องจัดการเมื่อไร (สั้น / กลาง / ยาว)

> 💡 **แก่นที่ต้องเข้าใจ:** Duration คือสิ่งที่ทำให้ SFAS มีค่า เพราะทำให้รู้ **ลำดับเวลา** ของกลยุทธ์ แผนของเรา "ฟื้นฟูก่อนแล้วโต" ก็มาจาก Duration โดยตรง

## A2. อ่านตัวเลขในตารางอย่างไร

- **Weight (น้ำหนัก)** = ปัจจัยนั้นสำคัญต่อยอดขายและกำไรแค่ไหน ผู้จัดทำกำหนด รวมกัน = 1.00
- **Rating (คะแนน)** มีเกณฑ์ 2 แบบ:
  - **ปัจจัยภายใน (S/W):** 4 = จุดแข็งหลัก · 3 = จุดแข็งรอง · 2 = จุดอ่อนรอง · 1 = จุดอ่อนหลัก
  - **ปัจจัยภายนอก (O/T):** วัด **ความสามารถของ MK ในการตอบสนอง** ไม่ใช่ความรุนแรงของปัจจัย · 4 = ดีมาก · 3 = ดี · 2 = พอใช้ · 1 = ต่ำ
- **Weighted Score** = Weight × Rating
- **คะแนนรวม** อยู่ระหว่าง 1 ถึง 4 **ค่ากลางคือ 2.5**

> ⚠️ จุดที่คนมักสับสน: T3 วัตถุดิบผันผวนได้ Rating **3** ไม่ได้แปลว่าอุปสรรคนี้เบา แต่แปลว่า **MK รับมือได้ดี** เพราะมีครัวกลางและจัดซื้อรวมศูนย์

## A4. วิเคราะห์ตารางให้ลึกกว่าที่ตารางบอก (Insight)

**② แยกตามประเภท**

→ น้ำหนักของ **W + T รวมกัน 0.55** มากกว่า S + O (0.45) แปลว่าในมุมของการตัดสินใจ ปัจจัยลบมีอิทธิพลมากกว่า

**③ W4 คือตัวเอก**

## A6. ทดสอบความเข้าใจ — อธิบายให้ได้ใน 1 ประโยค

- **SFAS คืออะไร** → "ตารางที่รวมปัจจัยภายในกับภายนอก คัดเฉพาะตัวที่สำคัญ แล้วบอกว่าต้องจัดการแต่ละตัวเมื่อไร"

# ส่วน C — Q&A และแบบทดสอบ

**Q1: ได้ 2.58 ซึ่งสูงกว่าค่ากลาง ทำไมยังเลือกฟื้นฟู?**
> "เพราะคะแนนรวมกลบปัญหาไว้ครับ ปัจจัยที่น้ำหนักสูงแต่คะแนนต่ำ คือ W3 W4 T1 T2 เป็นระยะสั้นทั้งหมด และกำไรส่วนบริษัทใหญ่ลดลงครึ่งหนึ่ง จาก 1,681.94 ล้านในปี 2566 เหลือ 837.96 ล้านในปี 2568 ถ้าขยายตอนนี้ก็คือขยายในช่วงที่อัตรากำไรยังลดลง แต่นี่เป็นการฟื้นฟูเพื่อเตรียมโตในปี 2572 ไม่ใช่การหดตัวถาวรครับ"

**Q2: ใช้เกณฑ์อะไรคัดจาก 20 เหลือ 12?**
> "เลือกปัจจัยที่มีน้ำหนักสูงต่อกำไรและมีผลโดยตรงต่อการเลือกกลยุทธ์ โดยเลือกด้านละ 3 ข้อให้สมดุล ตัวที่เป็นผลลัพธ์ เช่น W5 ยอดขายสาขาเดิม ใช้เป็นตัวชี้วัดใน BSC แทน และตัวที่เป็นเงื่อนไข เช่น S5 ฐานะการเงิน ใช้เป็นเหตุผลว่าทำไมฟื้นฟูได้โดยไม่ต้องกู้เพิ่ม"

**Q3: ทำไม W4 ได้ 1 แต่ W3 ได้ 2?**
> "W4 มีหลักฐานชัดที่สุดว่ากำลังแย่ลง อัตรากำไรขั้นต้นลดจาก 67.4 เป็น 64.6 และ 61.9 ในครึ่งแรกปี 69 ส่วน W3 ยังมีเครื่องมือแก้ได้บางส่วน เช่น ปรับกำลังคนและเวลาเปิดบริการ แต่เราไม่ได้สรุปว่ากำไรลดเพราะบุฟเฟต์อย่างเดียวครับ"

**Q4: ทำไม T3 ได้ 3 สูงกว่าอุปสรรคอื่น?**
> "Rating ของปัจจัยภายนอกวัดความสามารถในการตอบสนอง ไม่ใช่ความรุนแรง ครัวกลางและจัดซื้อรวมศูนย์ช่วยรับมือได้ แต่ยังจัดเป็นระยะสั้นเพราะค่าแรงและค่าเช่ายังกดดันอยู่"

**Q5: ทำไม W1 อยู่ระยะยาว แต่ W3 W4 อยู่ระยะสั้น?**
> "W3 กับ W4 กระทบกำไรทุกไตรมาส และแก้ได้ทันที ส่วน W1 ต้องสร้างแบรนด์อื่นให้โต ซึ่งใช้เวลาหลายปี จึงจับคู่กับ WO1 ในช่วงเติบโต"

**Q6: CPM บอกว่า CRG เหนือกว่า SFAS สะท้อนตรงไหน?**
> "สะท้อนใน S2 ที่ได้แค่ 3 เพราะ CRG มีจุดขายมากกว่า และสะท้อนใน T1 การแข่งขัน ซึ่งมีน้ำหนักสูงเป็นอันดับสอง (0.11)"

**แบบทดสอบเร็ว (ปิดคำตอบแล้วตอบเอง)**
1. SFAS เพิ่มอะไรที่ EFAS/IFAS ไม่มี? → *คัดปัจจัย · ให้น้ำหนักใหม่ · Duration*
2. คะแนนสูงสุดคือตัวไหน? → *S3 ครัวกลาง 0.40*
3. น้ำหนักสูงสุดคือตัวไหน? → *W4 บุฟเฟต์ 0.12 (R = 1)*
4. น้ำหนักรวมของกลุ่มระยะสั้น? → *0.48*
5. ระยะสั้นนำไปสู่กลยุทธ์อะไร? → *WT1–WT3 ฟื้นฟู 69–71*
6. ระยะยาวและกลางนำไปสู่อะไร? → *SO3 + WO1 เติบโต 72–73*
7. Rating 3 ของ O และ T หมายถึงอะไร? → *MK ตอบสนองได้ดี*
8. IFAS / EFAS / SFAS ได้เท่าไร? → *2.64 / 2.53 / 2.58*
