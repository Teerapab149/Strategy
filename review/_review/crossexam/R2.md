- **quote**: "สร้างยอดขายกลุ่มสินค้านวัตกรรมรักษ์โลกกว่า 158.64 ล้านบาท (คิดเป็นร้อยละ 23.77 ของยอดขาย)" · "บริษัทฯ มียอดขายสุทธิ 605.20 ล้านบาท"
- **problem**: F-R1-01 พบว่าแหล่งบริษัทระบุ 111.22 ล้านบาท ไม่ใช่ 158.64; F-R2-05 พบเพิ่มว่า 158.64 ถูกเลือกให้เท่ากับ 23.77% ของรายได้รวม 667.34 ล้านบาทพอดี ไม่ใช่ยอดขาย 605.20 ล้านบาท จึงเป็นทั้ง source conflict และ denominator-label error ใน claim เดียว
- **impact**: ตัวเลข headline ในบทสรุปดูคำนวณสอดคล้องเพราะใช้ตัวตั้งที่ถูกเปลี่ยน แต่ความสอดคล้องนั้นเกิดกับฐานผิดชื่อและขัดกับแหล่งต้นทาง ทำให้ spot check เพียงหนึ่งครั้งกระทบความน่าเชื่อถือทั้งเล่ม

- **check**: 158.64/667.34×100 = 23.7720%; 158.64/605.20×100 = 26.2128%; One Report ระบุ 111.22 ล้านบาท และ 111.22/605.20×100 = 18.3774%
- **fix**: คืนตัวตั้งเป็น 111.22 ล้านบาทตาม One Report และหยุดใช้ 23.77% จนระบุ denominator ต้นทางได้; หากต้องการสัดส่วนต่อยอดขาย 605.20 ให้คำนวณและรายงาน 18.38% พร้อม source/page
