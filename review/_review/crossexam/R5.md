# R5 — Cross-examination: Examiner Simulation

**เกณฑ์จัดลำดับที่ผมใช้ในเฟสนี้** — ผมไม่จัดลำดับตาม "แก้ยากแค่ไหน" แต่จัดตาม **ต้นทุนที่ผู้ตรวจจริงจะคิดคืน** ซึ่งมีสามชั้น

- **ชั้น A — เห็นก่อนตรวจอะไรเลย** (เปิดหน้า พลิกดู) ผู้ตรวจไม่ต้องเชื่อผมหรือใครก็เห็นเอง ข้อพวกนี้ตัดสิน "อารมณ์" ของการตรวจทั้งเล่ม และเป็นข้อที่ทำให้ผู้ตรวจเริ่ม *มองหา* ข้อผิดพลาดอื่นแทนที่จะอ่านตามน้ำ
- **ชั้น B — เห็นเมื่ออ่านตามลำดับ หรือถามคำถามเดียว** นี่คือชั้นที่ **คะแนนอยู่จริง** เพราะเป็นเนื้อหาที่รายวิชาสอน (Wheelen & Hunger: scanning → formulation → implementation → evaluation) ผู้ตรวจที่เป็นเจ้าของวิชาจะไล่สายนี้เป็นอาชีพ
- **ชั้น C — ต้องลงมือตรวจแหล่ง/คำนวณเอง** ผู้ตรวจส่วนใหญ่สุ่มตรวจไม่เกิน 2–3 จุด แต่ถ้าจุดที่สุ่มโดนเข้า ความเสียหายลามทั้งเล่ม ดังนั้นสิ่งที่กำหนดความเสี่ยงของชั้นนี้คือ **ตรวจง่ายแค่ไหนโดยไม่ต้องออกจากเล่ม** ไม่ใช่ผิดมากแค่ไหน

ข้อที่ผม ESCALATE ในเฟสนี้เกือบทั้งหมดคือข้อที่ **ตรวจได้จากภายในเล่มเอง** (ขัดกันเองในย่อหน้าเดียว / ขัดกับรูปที่นักศึกษาแปะเอง) ข้อที่ผม DOWNGRADE คือข้อที่ถูกต้องทางวิชาการแต่ผู้ตรวจแทบไม่มีทางเห็นและไม่เปลี่ยนข้อสรุปของเล่ม

## 2. ตอบ open question ที่จ่าหน้าถึง R5

**จาก F-R2-06 → R5: "การตั้งชื่อรูปควรเป็น 'รูปที่ n' ตามระบบเดียวกับ 'ตารางที่ n' หรือไม่"**

ตอบ: ควร และตอนนี้เล่มนี้ทำ **กลับด้านกับที่ควรเป็น** — ตรวจแล้วพบว่า **รูปมีเลขที่ (รูปที่1 ที่ P0073, รูปที่2 ที่ P0083) แต่ตารางทั้ง 8 ตารางไม่มีเลขที่แม้แต่ตารางเดียว** และแผนผังองค์กรที่ P0026 ก็ไม่มีทั้งเลขและ caption ข้อกำหนดที่ผมแนะนำให้ใช้ทั้งเล่ม:
